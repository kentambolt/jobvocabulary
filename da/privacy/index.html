Privatliv og kontakt

Dine fremskridt

Dine indstillinger, fremskridt, favoritord og egne lister gemmes i din browser. Du kan selv eksportere dine ordlister. Appen sender ikke dine ordlister eller besvarelser til vores statistiksystem.

Enkle brugstal

Vi tæller kursusstarter, første besvarelse og ti besvarede opgaver som samlede dagsoptællinger. Vi gemmer ingen besøgs-ID eller oplysninger, der kæder dine besøg sammen. Tallene viser hændelser, ikke unikke personer.

Målingen bruger ingen cookies eller browserlager. Vi respekterer browserens Do Not Track og Global Privacy Control. Hændelser sendes uden sidens adresse, henvisningsside, ord, svar eller oplysninger om dine lister.

Dagsoptællingerne modtages på vores server i EU og opbevares i 90 kalenderdage. Sikkerhedskopier kan indeholde ældre tællere i yderligere 14 dage. IP-adressen bruges kortvarigt til at beskytte mod misbrug, men gemmes ikke i statistikken og sendes ikke til Umami eller Google Analytics.

Oplæsning bruger din browsers talefunktion. Browseren eller styresystemet kan benytte en onlinetjeneste til at danne stemmen.

Siden leveres med GitHub Pages. Ved levering af siden modtager hostingleverandøren almindelige forbindelsesoplysninger, herunder IP-adresse. GitHub
