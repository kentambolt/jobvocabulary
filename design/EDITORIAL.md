# Editorial visual direction

The user's supplied JobVocabulary Editorial Web Design Showcase is the visual
reference. The implementation retains the compact exercise layout and uses warm
paper (#f7f4ee), forest green (#153f2e), dark green ink (#102c24), quiet borders,
Lora headings and DM Sans interface text. Mobile shows a text-led hero; desktop
adds the study-corner photograph. Native SVG paths provide the category icons,
benefit icons and subtle bottom landscape.

The default palette is deliberately light, independently of the OS appearance.
Explicit `data-theme="dark"` remains supported by the stylesheet.

## Generated photograph

Built-in ImageGen was used. The selected image was saved in the project as
`images/site/study-corner.jpg` (1536 × 1024, JPEG quality 85, approximately 165 KB).
The generated PNG remains in Codex's generated-images directory. JPEG encoding
only changes the delivery format; the photograph has not been retouched.
